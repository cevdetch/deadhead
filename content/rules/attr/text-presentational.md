Sixteen presentational attributes on text elements are obsolete. `<div align="center">`, `<hr width="50%" noshade>` and `<br clear="all">` are how text was set before CSS. The attributes centered blocks, shortened rules and cleared floats. They still turn up in old pages and in HTML generated by older tools.

## Why avoid

They are obsolete. The HTML Standard lists each spelling among the attributes that "are obsolete (though the elements are still part of the language), and must not be used by authors", with the instruction: "Use CSS instead." Section 16.3 still backs them with reflected IDL across the text interfaces, which is live machinery: the attributes keep working as presentational hints in the weakest place in the author cascade, where any stylesheet rule for the same property wins.

So deleting one repaints the text wherever no stylesheet rule covers the property. Each attribute either does nothing, because CSS overrides it, or sets a value the stylesheet never states. Either way, part of the page design lives in markup, where nobody editing the CSS will look for it. MDN files `clear` on `br` under deprecated attributes, and styles the `hr` rule through CSS.

## Use instead

Move the text chrome to CSS and drop the hints:

```html
<div>
  <p>Centered text</p>
  <hr>
</div>
```

```css
div p { text-align: center; }
hr {
  width: 50%;
  border: 0;
  border-top: 1px solid #ccc;
}
```

## Detectability

Complete detection. The rule reports each element once, however many hints it carries. It checks `div`, `p`, `h1` through `h6`, `legend`, `pre`, `hr` and `br`, and nothing else. There is no autofix: removing a live hint repaints the text, so the move to CSS needs a human look at the values.
